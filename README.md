# End-to-End Supply Chain Analysis

## Project Overview
This project focuses on analyzing supply chain operations to understand shipment performance, supplier efficiency, inventory levels, transportation costs, and warehouse performance.

The objective is to identify operational challenges and generate data-driven insights to support better business decisions.

## Business Objectives
- Analyze shipment and delivery performance.
- Identify supplier performance gaps.
- Monitor inventory and stock levels.
- Evaluate transportation and shipping costs.
- Analyze warehouse and location performance.
- Support better supply chain decision-making.

## Tools & Technologies
- Python – Data Cleaning and Exploratory Data Analysis
- MySQL – Data Analysis and SQL Queries
- Power BI – Interactive Dashboards and Visualization
- Excel – Data Handling and Preparation
- GitHub – Project Documentation and Version Control

## Key Analysis Areas

1. Shipment and Delivery Analysis
2. Supplier Performance Analysis
3. Inventory Analysis
4. Transportation Cost Analysis
5. Warehouse and Location Performance

## Business Value

The analysis helps understand potential shipment delays, supplier performance issues, inventory challenges, and transportation cost variations.

It provides a foundation for improving operational efficiency and supporting data-driven business decisions.
